# Redux Toolkit (RTK) Guidelines

## 1. Directory Structure

We use a feature-based structure for Redux Toolkit to cleanly separate states and APIs:

- `lib/store/store.ts`: The main Redux store configuration.
- `lib/store/hooks.ts`: Typed hooks (`useAppDispatch`, `useAppSelector`, `useAppStore`).
- `lib/store/features/<feature-name>/`: Contains logic for a specific feature domain.
  - `<feature-name>Slice.ts`: Client-side state managed by standard Redux slices.
  - `<feature-name>Api.ts`: Data fetching and network states managed by RTK Query.

> **Note:** We also have a `StoreProvider` located at `components/providers/StoreProvider.tsx` to wrap the Next.js App Router application.

## 2. Adding a New State Slice

When you need purely client-side state (like UI toggles, caching local forms):
1. Create `lib/store/features/<feature>/<feature>Slice.ts`.
2. Use `createSlice` to define the initial state, reducers, and actions.
3. Export the custom actions (e.g. `export const { toggleTheme } = themeSlice.actions;`).
4. Export the reducer.
5. Import this reducer into `lib/store/store.ts` and add it to the Redux `reducer` object.

## 3. Adding a New API (RTK Query)

Whenever you need to call the backend:
1. Create `lib/store/features/<feature>/<feature>Api.ts`.
2. Use `createApi` and `fetchBaseQuery`. Define the base URL properly with environment variables.
3. Define your endpoints (use `builder.query` for GET requests, and `builder.mutation` for POST/PUT/DELETE requests).
4. Export the autogenerated hooks directly (e.g. `export const { useGetItemsQuery, useCreateItemMutation } = featureApi;`).
5. Import the API reducer and middleware into `lib/store/store.ts` to connect it to the store.

## 4. Usage in React Components

- **Read state**: `const user = useAppSelector(state => state.auth.user);`
- **Mutate state**: `const dispatch = useAppDispatch(); dispatch(logout());`
- **Fetch data (Query)**: `const { data, isLoading } = useGetProfileQuery();`
- **Submit data (Mutation)**: 
  ```tsx
  const [loginWithGoogle, { isLoading }] = useLoginWithGoogleMutation();
  // Call it on button click
  await loginWithGoogle({ idToken: '...' }).unwrap();
  ```

## 5. Google Login API Integration Example

See `lib/store/features/auth/authApi.ts` and `authSlice.ts` for a demonstration of connecting Google Login. 
**Flow:**
1. The Frontend receives an `idToken` from Google OAuth (usually via `@react-oauth/google`).
2. The user triggers `loginWithGoogle({ idToken: '...' })`.
3. RTK Query calls `POST /api/auth/google-login` passing the `idToken` to the backend.
4. The Backend verifies this `idToken` with Google Servers, finds or creates the user, and returns its own internal JWT `accessToken`.
5. Frontend takes the returned `accessToken` and user object, and stores it in Redux (`dispatch(setCredentials(...))`).
6. Subsequent authenticated RTK Query calls will automatically inject the JWT in the `Authorization: Bearer` header.
